# NihongoHub

NihongoHub は、単語管理と語彙練習を中心とした日本語学習プラットフォームです。

本プロジェクトでは、単語を独立したデータとして管理し、複数の単語帳で再利用できる柔軟な語彙管理システムを目指しています。ユーザーは、JLPT のレベル、テーマ別の語彙、独自の学習教材など、目的に応じて単語を単語帳に整理できます。

初期開発では、単語帳、単語管理、クイズ機能を中心に実装します。将来的な学習機能の拡張も考慮した構成とし、Web フロントエンドや、将来開発する可能性のあるモバイルアプリから共通の HTTP API を利用できる設計を目指しています。

> **開発状況：** 現在は初期開発段階であり、通常利用できるリリースはまだありません。API、データモデル、設定形式などは、今後互換性のない形で変更される可能性があります。

## 主な機能

- 漢字、かな、ピッチアクセント、意味、メモなどを含む日本語語彙の管理
- 独自のタグを設定できる単語帳
- 1 つの単語を複数の単語帳で再利用
- 選択した単語帳をもとにした語彙クイズ
- ユーザー認証および管理機能

これらはプロジェクトで実現を目指す機能であり、すべてが実装済みというわけではありません。

## 技術スタック

- **バックエンド：** C# / ASP.NET Core Minimal API（.NET 10）
- **データベース：** LiteDB
- **認証：** JWT
- **ログ：** Serilog
- **フロントエンド：** HTML、CSS、JavaScript

## リポジトリ構成

- `src/` — バックエンドのソースコード
- `web/` — フロントエンドのソースコード（予定。現在のリポジトリには未作成）

## 開発

ビルドには .NET 10 SDK が必要です。

```bash
dotnet build src
```

本プロジェクトは現在開発中のため、現時点では本番環境での利用を想定していません。
