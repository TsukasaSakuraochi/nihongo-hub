# NihongoHub

NihongoHub 是一个专注于日语词汇管理与练习的日语学习平台。

本项目旨在构建灵活的词汇管理系统：每位用户的单词均作为独立记录进行管理，并可以在多个单词本之间重复使用。用户可以根据不同的学习目的组织单词，例如按照 JLPT 等级、主题类别或自定义学习材料进行整理。

项目初期主要关注单词本、单词管理和测验功能。整体架构也为未来扩展更多日语学习功能预留了空间，并计划通过统一的 HTTP API 为 Web 前端以及未来可能推出的移动应用提供服务。

> **开发状态：** 项目目前处于早期开发阶段，尚无可供正常使用的正式版本。API、数据模型和配置格式未来可能发生不兼容的变更。

## 核心功能

- 日语词汇管理，包括汉字、假名、音调、释义和备注
- 支持自定义标签的单词本
- 单词可以被多个单词本重复引用
- 根据选定的单词本组合生成词汇测验
- 用户认证与管理功能

以上内容描述的是项目的计划范围，并不代表所有功能均已实现。

## 技术栈

- **后端：** C# / ASP.NET Core Minimal API（.NET 10）
- **数据库：** LiteDB
- **身份认证：** JWT
- **日志：** Serilog
- **前端：** HTML、CSS 和 JavaScript

## 仓库结构

- `src/` — 后端源代码
- `web/` — 前端源代码（计划目录，当前仓库尚未包含）

## 开发

需要安装 .NET 10 SDK。

```bash
dotnet build src
```

项目仍处于积极开发阶段，当前不建议用于生产环境。
